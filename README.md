# AdGuard Home GUI

A lightweight Windows tray controller for AdGuard Home.

## Features

- Start/Stop AdGuard Home Windows Service
- Minimize to system tray
- Open AdGuard Home Dashboard
- Enable/Disable DNS Protection (coming soon)

## Requirements

- Windows 10/11
- .NET 8 Runtime
- AdGuard Home installed
